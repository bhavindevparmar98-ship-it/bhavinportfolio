# Bhavin Parmar Portfolio

A standalone portfolio landing page implemented in plain HTML, CSS, and JavaScript.
It has no build step or package dependencies.

**Live Demo:** https://bhavin-portfolio.vercel.app/  
**GitHub Repository:** https://github.com/bhavindevparmar98-ship-it/bhavinportfolio

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server, for
example:

```sh
npm start
# or
python3 -m http.server 8000
```

Then open `http://localhost:8000` or `http://localhost:3000` depending on your server.

## Deployment

This project is deployed on **Vercel**. To redeploy:

1. Push changes to the `main` branch of the GitHub repository
2. Vercel will automatically build and deploy the changes
3. The site will be available at https://bhavin-portfolio.vercel.app/

## Content

The experience, skills, project, and contact content comes from the supplied portfolio
code. No education or employment-history details were provided, so none have been
invented or added.

## Features

- Responsive design with mobile-first approach
- Clean, modern typography using Google Fonts
- Smooth navigation and interactions
- SEO-optimized with Open Graph and Twitter Card meta tags
- Progressive enhancement with no external dependencies
